# 安装与下载台账

> **用途**：登记项目过程中所有安装与下载，保证结项/阶段收尾时能干净清理，不把东西散落在机器里。
> **纪律**（见 AGENTS.md）：每次 brew/pip/npm 安装、模型/数据下载、软链创建，**当下即登记**；状态随使用情况更新。
>
> - **项目内**条目：位于本仓库目录中，gitignore 不入库，可自主清理（可再下载/重建）。
> - **系统级**条目：散落在机器里（brew、~/.local/bin、~/.config 等），清理前列清单交用户确认后再动。

## 清理原则（阶段收尾执行）

1. 选型结论落定后：**未中选**引擎的模型文件与 pip 包即从台账转「可清理」。
2. `runs/` 下的大文件（音频、临时产物）在对应调研报告完成后清理，结论已沉淀进 `docs/research/`。
3. 系统级条目（brew 包、软链）清理前，列清单交用户确认。
4. `vendors/` 若评估后不采用，直接删目录（台账销账）；若采用为依赖，转为正式集成方式并销此台账条目。
