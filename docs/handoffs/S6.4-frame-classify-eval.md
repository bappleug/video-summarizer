### B. 取帧质量评测 harness（新 tests 级工具 + 脚本，放 tools/bili-digest/eval_frames.py 或 tools/asr-bench 风格独立脚本目录，你定）
1. **稠密金标模式**：`--gold <视频或 run 目录>`——每 12 秒均匀撒帧，VLM 全量分类，输出「内容状态时间线」JSON（状态区间+类型）到 runs/eval-frames/<video>/gold.json。
2. **打分模式**：`--score <run目录>`——取该 run 实际保留帧 vs gold.json，输出记分卡：内容覆盖率（金标内容状态被命中比例）、精度（内容帧占比）、冗余度（每状态平均帧数）、frame_type 分布、花费。
3. **Contact sheet**：`--sheet <run目录>`——生成单页 HTML（缩略图网格+时间码+frame_type+描述首行），人审 30 秒级。
4. 评测脚本可用真实 VLM（评测场景专用，花费在验收预算内），核心打分逻辑（时间线命中计算）用合成数据单测。
