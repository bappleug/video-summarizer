# S6.2 交接文档 — 敏感边界检测替代盲网格（ppt/auto 模式取帧主路升级）

> 2026-11-21 · 用户设计共识：PPT 同底版下「翻页」与「页内元素显现」的分数尖刺不可分且无需区分——目标是**每个视觉稳定状态的最全帧**；策略 = 宁多勿漏检测 + 下游清洗兜底（清洗链 S6.1 已建成）。前置：S6.1（578f9e7）。

## 改动范围（仅 frames.py 取样策略 + 测试）

**新主路：尖刺检测采样**（ppt 与 auto 模式共用，参数不同）
1. 取分数序列：ffmpeg 逐帧 scene 分数全量输出（如 `-vf "select='gte(scene,0)',metadata=print"` 方向，自行验证可用形式；381s/25fps≈9500 点，本地几秒跑完）。
2. **双条件触发（满足其一即尖刺）**：自适应 `score > 中位数 + 3×MAD`（或等价稳健波动度量）**或** 绝对底线（ppt 模式 0.008、auto 模式 0.015，可调常量）。
3. 尖刺合并：0.5s 内连刺取峰顶算一次（淡入淡出会产生连刺）。
4. 采样：每个尖刺 t 取 `t-0.25s` 帧（边界前=该状态最全）；**额外补片尾帧**（`duration-0.3s`，最后一页没有下一次翻页来触发）。
5. 候选不足（尖刺 <3，近静止视频）→ 回退现有网格策略（ppt 5s / auto 10s，S6.1 逻辑保留不动）。

**清洗层不动**：pHash 聚簇取末（微尖刺产生的重复帧在此合并）、簇内边缘密度仲裁、cap（ppt 40 / auto 20）、auto 的两级门控全部照旧。

**设计不变式**（单测守护）：检测层允许假阳性（多截无害，聚簇清洗），不允许假阴性（漏状态无补救）；`--visual=ppt` 不受门控影响。
