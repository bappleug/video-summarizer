## 工作项

1. **统一重提帧（关键）**：样本 2-5 的既有 run 是旧策略产物，不可直接打分。对每条本地视频用**当前代码**离线重跑取帧+VLM 分类（复用 eval/管线库函数，产物放 runs/eval-frames/<id>/current/）；样本 2 先完整在线管线（`digest <url> --visual --summarize`，B站 API ≤3 + 1 下载）。
2. **逐样本 gold + score**：gold 12s 稠密（新视频需跑；样本 3-5 需跑），score 出记分卡。**冗余真伪验证**：同金标状态内逐对 pHash 汉明距离——≤8 记「真冗余」（近似重复），>8 记「子状态」（金标粒度下的额外信息），按样本报告两者占比。
3. **跨形态记分卡**（本轮核心交付）：5 样本 × {覆盖率/精度/冗余度/真冗余占比/帧数/VLM 花费}，附一句每形态结论。
4. **定版建议**：按数据给结论——若无形态明显短板（建议线：混合类覆盖率 ≥45%、PPT 类 ≥90%、图文卡 ≥90%、精度全 ≥90%），建议「取帧 v1.0 定版」；若有短板，列出具体参数方向（只建议不动手）。
