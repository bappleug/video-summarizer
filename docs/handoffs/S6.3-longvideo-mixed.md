## 工作项

### A. 混合模式（frames.py + pipeline，主路不动）
1. **cap 按时长伸缩**：`cap = min(上限, max(基础cap, ceil(duration/30)))`——auto 上限 60、ppt 上限 60（40→60，长 PPT 课不漏页）；短视频行为不变（回归保障）。
2. **静态簇优先**：候选超 cap 时，抽稀顺序改为——动态段（簇存在时间 < 2s 或属于密集切变区）先抽稀到稀疏代表（每 30s 至多 1 帧），静态簇（稳定 ≥2s）保配额；仍超则按簇时间均匀抽稀。
3. **视频流清晰度约束**（长视频下载体积控制）：video 下载选流时限制在 ≤720p（读图足够），优先 h264；meta 记录所选流与体积。
4. （可选加分，时间允许才做）VLM 信息价值标注：候选 >40 时给每帧 `informational: high/mid/low`，抽稀时低价值帧先弃。做不动就不做，如实记录。
