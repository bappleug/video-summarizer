## 怎么升级

```bash
cd ~/ai-tools/video-summarizer     # 换成你自己的 clone 目录
git pull
```

显示 `Already up to date.` 说明已是最新；显示一串文件名说明升级完成。两种情况都不需要再做别的。

**如果 `git pull` 报错** `Your local changes to the following files would be overwritten by merge`：说明这台机器改过仓库里的文件（常见是 `README.md` / `AGENTS.md`）。先把改动临时收起，拉完再放回：

```bash
git stash
git pull
git stash pop
```

其它情况**不要自行处理**，把终端里 `git status` 与 `git log --oneline -3` 的输出发给维护者：

- `git stash pop` 报冲突（CONFLICT）；
- 报 `untracked working tree files would be overwritten`（clone 目录里已有同名的 `docs/` 或 `scripts/`）；
- 报 `divergent branches`（这台机器上有没推送过的本地提交）。

## 升级后自检

1. 在 MCP 客户端里**重载一次 MCP**（或重启客户端）。
2. 对 Agent 说「**开始用 bili-digest**」：Agent 会调用体检工具 `digest_doctor`，结论应为「无异常」（✘ 是异常项，△ 只是可按需优化的提醒）；升级前就有的 ✘ 不应变多。
3. 不用 MCP 也可以在终端体检：

   ```bash
   cd ~/ai-tools/video-summarizer
   PYTHONPATH=src .venv/bin/python -m bili_digest.cli doctor
   ```

4. 丢一个视频链接试用，能正常出文字稿或报告即完成。
